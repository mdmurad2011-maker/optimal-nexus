# OPTIMAL NEXUS Mobile

This directory contains the Flutter client application for OPTIMAL NEXUS.

## Purpose

The mobile client will provide:

- Secure authentication
- User profile
- Support ID
- Device registration
- Remote support requests
- Connection approval
- WebRTC communication
- Screen sharing
- Session management

## Platform

- Flutter
- Dart
- Android

## Development Rule

The application must use real OS-supported functionality and proper user permissions.

No fake remote-control or simulated connection functionality will be used in the production implementation.
